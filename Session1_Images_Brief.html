Background

What you are classifying, and why

Skeletal muscle is a mixture of two fibre types. Type I fibres contract slowly, are packed with mitochondria, run on oxidative metabolism and resist fatigue — they do the work of holding you upright. Type II fibres contract fast, run on glycolysis, and produce power at the cost of fatiguing quickly. In cross-section the two types are interleaved in a mosaic, and their proportions shift measurably with training, ageing and disease. That proportion is exactly what muscle pathology and exercise physiology measure.

In this activity, the MERSCOPE platform has been used to capture six fluorescence channels from 10 fields of view across 5 slides from 9 subjects, and the fibre boundaries have already been segmented with Cellpose.

The heart of the problem

The three channels you get — DAPI (nuclei), Cellbound3 (cell membrane) and PolyT (total RNA) — are not fibre type markers but do provide indirect evidence: Type I fibres carry more mitochondria and are transcriptionally busier, so PolyT runs brighter; membrane and capillary architecture differ, which shows up in Cellbound3 texture; myonuclear density and arrangement differ too, which shows up in DAPI. Reading fibre type out of evidence that indirect is what makes this an interesting challenge!

Building the dataset

We've done this for you, but you can edit if you wish

Initially the whole fields of view are loaded, three channels each, plus a label mask. Each field of view is one .npz holding two arrays that line up pixel for pixel: 

images   (3, H, W) uint16    DAPI, Cellbound3, PolyT — raw fluorescence
labels   (H, W)    uint16    labels[y, x] == k  ->  that pixel belongs to fibre k
                             0 is background

Fields of view run from 793 × 2176 to 3393 × 2650 pixels and hold between 21 and 266 fibres. fibre_index.csv maps each (fov, label_id) to a fibre_uid, which is what labels and submissions are keyed on.

The notebook provides code to extract fixed-size crops of each fibre. It first walks through one example so you can see how the image and segmentation mask fit together, then applies the cropping function to the dataset. Each crop includes a margin around the fibre and handles image borders. You can use the supplied function and focus on exploring the images, extracting features and improving your classifier. If you would like an additional coding challenge, you can adapt the cropping function and test it with checkCrop().

Where the reference labels come from

We assigned fibre types using separate fluorescence marker channels: MYH7 for Type I and ATP2A1 plus MYH1 for Type II. These marker channels are not included in your dataset. Your task is to predict these labels using the three supplied image channels.

Input
The whole-field-of-view images and labels arrays, and anything you derive from them.
Baseline
GLCM, LBP, gradient and intensity features from all three channels into L2 logistic regression: balanced accuracy 0.566, AUC 0.614 under slide-wise cross-validation. Shape features (derived from the mask) alone score 0.52 in our experiments so the image data may be more informative.

Getting started

Everything is in one Google Drive folder: Muscle_Fibre_Hackathon. Add a shortcut to your own Drive, then right-click Session1_Images.ipynb and choose Open with → Google Colaboratory.

If you plan to use a GPU (optional), before you run anything, switch the runtime to a GPU: Runtime → Change runtime type → T4 GPU. The first cell mounts your Drive and copies the 307 MB of data onto the Colab machine, which takes about a minute.

Evaluation and submission

  1. Balanced accuracy and AUC. The classes are close to 50/50 overall, but the proportion within a single slide ranges from 21% to 66%, so a model that quietly learns the per-slide prior will look better than it is.
  2. The code is configured to train on slides 1, 5, 9 and 17A; and there is a heldout test slide 18A — 172 fibres with labels withheld. The submission cell automatically retrains your chosen classifier on all training fibres.
